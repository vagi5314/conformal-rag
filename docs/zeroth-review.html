// the problem

RAG systems hallucinate.
There's no guarantee they won't.

RAG augments LLMs with retrieved context to reduce hallucination. But even state-of-the-art models generate plausible-sounding claims unsupported by context.

no statistical guarantee uncalibrated confidence no abstention mechanism
example.json
// Query:
"What year was the Eiffel Tower built?"

// Context:
"Eiffel Tower, Paris, 330 meters tall..."

// LLM Response:
"The Eiffel Tower was built in 1889
 for the World's Fair."

// What if the context didn't say 1889?
// The LLM would still say it confidently.
// That's a hallucination.

// why existing solutions fail

Heuristics don't give guarantees.

Embedding Similarity

Compares vector distances. 100% FPR on real hallucinations (Semantic Illusion, Dec 2025). RLHF models produce undetectable hallucinations in embedding space.

FAILS

NLI-Only Scoring

Entailment classification. F1 ~0.35 on RagTruth++. Fast but insufficient alone. No calibration threshold.

PARTIAL

LLM-as-Judge

GPT-4 evaluates correctness. 7% FPR. But expensive ($0.001-0.01/query), no statistical bound.

PARTIAL

No existing tool provides a mathematically guaranteed hallucination rate bound for RAG.

3 / 10
// our approach

Conformal Risk Control for RAG

Instead of heuristic confidence, we use conformal prediction to provide a finite-sample guarantee:

P(hallucination | not abstained) ≤ α
01   Score each response with NLI + optional LLM judge
02   Calibrate threshold on labeled data
03   Abstain when risk exceeds threshold
04   FDR is bounded by alpha with finite-sample guarantee

Key Insight

Standard conformal prediction gives coverage: "the correct answer is in the prediction set."

Conformal Risk Control (Angelopoulos et al., 2024) gives risk control: "the probability of hallucination is bounded."

This is what production RAG needs: FDR ≤ alpha, not just coverage.

Scoring Pipeline

NLI fast path catches 70% of clear cases. LLM judge verifies uncertain 30%. 70% cost reduction vs LLM-only.

Online ACI

Adaptive Conformal Inference (Gibbs & Candes, 2021). Adjusts threshold on streaming data. Handles distribution drift.

Per-Domain

Different alpha per domain. Finance: alpha=0.01. Medical: alpha=0.001. General: alpha=0.05.

// contributions

What's new

FDR-Guaranteed Detection

First production implementation of Conformal Risk Control for RAG hallucination FDR. Not just coverage — actual hallucination rate bound.

Hybrid NLI + LLM Scoring

Two-stage scorer combining fast DeBERTa-v3 NLI with optional LLM judge via LiteLLM. Cost-optimized: NLI filters 70% of cases.

Per-Domain Calibration

Topic-specific threshold adaptation. No other tool calibrates per domain. Prevents over/under-covering in multi-domain deployments.

Online Adaptive Update

Newton-update ACI adjusts thresholds on streaming data. Handles distribution drift without full recalibration. Based on Gibbs & Candes 2021.
