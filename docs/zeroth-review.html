What's
new here

Four contributions that fill gaps no existing tool addresses.

FDR-Guaranteed Detection

First production CRC implementation for RAG hallucination FDR. Not coverage — actual hallucination rate bound.

Hybrid NLI + LLM Scoring

Two-stage scorer: fast DeBERTa-v3 NLI + optional LLM judge via LiteLLM. Cost-optimized pipeline.

Per-Domain Calibration

Topic-specific thresholds. Finance: α=0.01. Medical: α=0.001. No other tool does this.

Online Adaptive Update

Newton-update ACI adjusts thresholds on streaming data. Handles distribution drift (Gibbs & Candes, 2021).
