⚡ Add-ons to Reduce Free Tier LLM Burn

1. NLI-Only Fast Path

Skip LLM judge when NLI confidence > 0.7. Catches 70% of cases. Saves 70% LLM calls

2. Verdict Caching (Redis)

Cache LLM verdict per (doc_chunk, query_hash). Same chunk judged once, reused forever. Saves 80% on repeated queries

3. Offline Bulk Calibration

Run calibration in batch (not per-query). 1000 samples = 1 LLM batch call. Saves 99% calibration cost

4. Provider Rotation

Rotate Groq → OpenRouter → Together → Cerebras. Each gives 500-1000 free req/day. Total: 3000+ free req/day

5. Response Caching

Cache LLM responses for (query + context hash). Same query = no API call. Saves 50% on cache hits

6. Confidence-Gated Routing

Low-stakes queries → NLI only. High-stakes → full LLM judge. Saves 60% on routine queries
